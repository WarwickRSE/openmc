OpenMC Event-Based Parallelism
===============================

settings::event_based selects OpenMC's event-based transport algorithm instead
of the default history-based algorithm.

- History-based: OpenMC follows one particle through its entire history before
  moving to the next.
- Event-based: OpenMC keeps many particles in memory and groups work by event
  type, such as moving particles, collisions, and surface crossings.

Event-based mode can improve CPU/GPU-style parallel efficiency and data locality
for large problems, but it uses more memory. Its buffer size is controlled by
settings.max_particles_in_flight (default: 100000).

Enable it in Python with:

    settings.event_based = True

or at runtime with:

    openmc.run(event_based=True)

For a small water-block example, it is unlikely to help much; the default
history-based mode is the straightforward choice.

No. `macro_xs().total` is the material’s total interaction rate per unit path length, $\Sigma_t$ in $\mathrm{cm}^{-1}$.

It determines the sampled distance to the next collision:

$$d = -\frac{\ln(\xi)}{\Sigma_t}$$

It does **not** describe energy loss.

For your proton model, energy loss should be a separate stopping-power quantity, commonly:

$$S(E) = -\frac{dE}{dx} \quad [\mathrm{eV/cm}]$$

At each transport step of length $d$, apply:

$$E_{\mathrm{new}} = \max(0, E_{\mathrm{old}} - S(E_{\mathrm{old}})d)$$

You can use `macro_xs().total` to schedule discrete scattering/nuclear events, while handling continuous ionization loss separately during the particle advance.

For a neutron, `particle.macro_xs()` contains macroscopic cross sections in units of inverse length:

- `total`: probability per unit path length of **any neutron collision**. It includes absorption plus scattering:
  \[
  \Sigma_t = \Sigma_a + \Sigma_s
  \]
- `absorption`: probability per unit path length that the neutron **disappears from the neutron population**, including capture and fission. It excludes scattering.

Thus:

```cpp
p.macro_xs().total - p.macro_xs().absorption
```

is the effective scattering cross section used for non-absorbing collisions. `total` determines when and which nuclide a collision occurs; `absorption` determines whether the collision removes neutron weight or terminates the neutron.
